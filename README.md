# Scoot Vacations

A premium, modern, and cinematic travel agency website built with React and Vite.

## Features
- **Responsive Layout:** Beautiful rendering on Desktop, Tablet, and Mobile devices.
- **Cinematic UI:** Smooth transitions, depth-enhancing shadows, and curated fonts (Inter & Outfit).
- **Service Highlights:**
  - Premium Tour Packages
  - Resort and Hotel Bookings
  - Professional Transport / Bus Bookings
- **Lead Generation:** Optimized for direct WhatsApp communication and direct call tracking.
- **Visual Proof:** Includes CSS Masonry grids for Travel Moments and Testimonial cards.

## Quick Start Local Development

1. Ensure you have Node.js installed.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open your browser and navigate to `http://localhost:5173/` to view the site.

## Stack
- Vite
- React
- Lucide React (Icons)
- Vanilla CSS (CSS Variables styling)
